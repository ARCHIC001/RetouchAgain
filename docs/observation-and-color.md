# 观察、图像角色与色彩/几何合同

> 发布派生版/非历史原稿。本文提取输入和观察机制，不包含照片、视觉结论、配方答案或实验成绩。

## 1. 先确认图像角色

| 角色 | 用途 | 与其他角色的区别 |
|---|---|---|
| 作者成片目标 | 可见摄影目标与参考 | 不是后端默认显影，也不是任意基础预览 |
| RAW 或合格中间源 | 真正编辑输入 | 要核查实际解码、相机颜色及初始状态 |
| RAW 基础显影预览 | 方便初看源图内容 | 已经显影，不等于线性传感器数据或当前后端基线 |
| 后端 v0 | 当前后端建立的干净初始呈现 | 只作实际编辑基线，不改称作者目标 |
| 父/子候选 | 一次实际操作前后的结果 | 用于动作后果判断，不作作者参考 |
| 实际导出 JPEG | 交付物及 G4 观察来源 | 与过程 PNG 不同，必须实际解码再看 |
| 合成夹具/已知刺激 | 工程与后果诊断 | 与作者目标和真实摄影效果分开 |

作者目标默认使用已准备的短边 512 副本，并做实际 ICC 转换。
原尺寸目标仅在明确需要时另行使用，不因有备份就默认扩大数据读取。
发布仓库仅以 DSC_3734 的NEF、普通JPG和o前缀JPG提供对应三种职责的示例；其他资产不包含。
普通目标是512×768 Display P3，o前缀预览是512×768 sRGB，两者均按原字节保留。
这些不是后端v0或实验结果；独立使用时仍需核查素材/后端资格并实际转换ICC。

## 2. 实际 ICC 转换

RGB 数字必须连同 ICC/传递函数解释；Display P3 与 sRGB 同数值不表示同一颜色。
目标先按其真实 ICC 转到 sRGB，而不是把配置名称替换为 sRGB。
过程观察与最终交付采用明确色彩条件；模型附件是 upright、RGB8、sRGB PNG。
附件清除任意 EXIF/text，避免派生后再次应用方向或泄漏源元数据。
原始高精度母版保持，显示派生不向源文件回写。

已显影 JPEG/PNG/TIFF 走独立源路由，验证 ICC、位深、方向和 alpha 声明。
16-bit 关键颜色转换前不先降为 8-bit；灰度、CMYK、透明和显式 linear 需要明确分支。
无 ICC 或线性含义不明时不静默假设 sRGB。
反解 JPEG 的传递函数只得到显示线性数据，不恢复 RAW 的高光或相机光谱信息。
全局 WB 的有效单位也依赖实际源类型，不能沿用另一类源的数值解释。

## 3. RAW geometry 与完整画布

RAW 契约按实际选中 IFD 区分 CFA 与 LinearRaw，不强迫后者伪装成 Bayer 数据。
核查内容包括样本布局、完整尺寸、相机矩阵/白平衡、初始设置及显示参考。
画面几何按有序关系处理：实际 RAW IFD → ActiveArea → DefaultCrop → orientation → 显示网格。
不能仅排序宽高后认为方向正确，也不能读主 IFD 缩略图冒充完整 RAW。
单次方向归一与相机几何是一致的合同，不在不同层重复旋转。

后端先完整分辨率渲染，再派生过程观察和最终 JPEG 的小图。
源与各渲染使用同一原始画布派生网格，只允许可解释的像素取整。
不把不同宽高比强行拉伸到固定模板，也不暗中裁切、旋转或透视修正。
RAW 的源级显示参考可用于固定 tone 呈现；它不是作者目标或可编辑像素替身。
不能用作者隐藏 XMP 配方补偿基线，再把结果称为纯视觉仿色。

## 4. opacity 与无效拼接区

独立 DNG opacity 平面与真实 RAW 几何一起裁幅/定向，不能用猜测的语义蒙版替代。
在明确的线性 sRGB 中以白色背景合成，再重新编码作为显示/导出图。
可写为 `C_linear = alpha * RGB_linear + (1 - alpha) * white`。
无效拼接区不是照片中的白色高光，不进入实景高光判断或区域颜色目标。
保留完整画布，不因白边影响观察就自动裁掉。

## 5. Tone 的统一灰度公式

灰度是观察派生，不是把 RAW 切到黑白显影，也不改彩色母版和设置。
对 ICC 转换后的 sRGB 通道 `c ∈ [0,1]`，先解码：

```text
c_linear = c / 12.92                         if c <= 0.04045
           ((c + 0.055) / 1.055) ^ 2.4     otherwise
Y = 0.2126 R_linear + 0.7152 G_linear + 0.0722 B_linear
s = 12.92 Y                                if Y <= 0.0031308
    1.055 Y^(1/2.4) - 0.055                otherwise
RGB_gray = round_half_up(255 * clip(s, 0, 1))，三个通道相同
```

两图使用同一转换，无 auto-level、无独立直方图匹配，不各自“自动修正”曝光。
Tone 送灰度；G1/G2/G3/G4、Color 和 Joint 送彩色。
灰度减少颜色观感对明暗判断的干扰，但不证明影调和颜色在实际编辑中完全解耦。

## 6. target 与 effect 是不同问题

`target` 比较作者目标与当前版，回答“离想要的呈现还有什么差距”。
`effect` 比较实际父版与当前子版，回答“这一操作真正带来了什么”。
effect 的 reference 是实际父版，不是作者；两图需绑定同一实际操作和版本关系。
编辑后优先复核后果，必要时切目标检查点；不机械每步增加两次请求。
支持本轮预期与达到作者目标是独立结论，详见[工作记忆](memory-and-task-routing.md)。

## 7. ROI、网格与对应资格

总览最长边不超过 512，局部最长边不超过 384；两附件保持可辨，不用巨型拼图代替。
4×4 网格是元数据定位，不烧进摄影像素；每张图各有独立归一坐标。
相同格号不代表同一物理区域，更不证明目标与源图已经配准。
参考 ROI 与源 ROI 分别定位，确认对象、材质、受光及摄影角色后才决定比较资格。
“白衣”“天空”等标签不够；受光面与阴影面、反光与漫反射可能承担不同角色。
同源文件名、相似尺寸和宽高比都不能自动建立像素对应。

同版本同阶段的 ROI 补证不抹掉已送达全图；版本/导出改变后旧证据不能冒充新图。
后果对比在实际父子相同画布上用同一 ROI；目标对比可用独立框与明确角色映射。
ROI 是观察窗，不自动成为 Linear/Radial 蒙版几何。
保护检查包含核心区、羽化邻域及区外影响，不只看框中心。

## 8. 可选测量与目标适用性

纯视觉分支不默认给模型附上 LAB 取样；测量研究条件另行配置。
需要测量时在统一 sRGB→CIELAB D65 实现上取原实际图区域统计，不从拼图取数。
框内 LAB 中位数是测量定义，不是审美分数；分布与渐变必要时另查。
`same_region` 才计算相应目标残差；仅角色对应的 `role_only` 不伪造精确残差。
变化为当前减实际基版，残差为目标减当前。
跨照片迁移先决定迁移精确值、区间、方向还是关系；不把参考读数直接当源图答案。
LAB 方法指导、数值反馈、直接 Lab 编辑和外部接受规则是四种不同机制。
