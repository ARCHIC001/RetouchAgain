# 视觉观察、图像角色与色彩/几何契约

视觉 Agent 的判断质量直接取决于输入图像是否准确、一致。本文档说明 VisHarness 如何管理图像角色、处理色彩空间与 RAW 几何，以及如何构造对比用的局部观察图。

## 1. 图像角色定义

系统为管线中的每一类图像赋予明确身份，确保对比基准清晰：

| 图像角色 | 用途 | 处理方式 |
|---|---|---|
| **作者成片目标（Author Target）** | 仿色的最终视觉参考 | 默认使用经真实 ICC 转换的短边 512 副本；需要细节核查时可读取原尺寸版本 |
| **RAW / 中间源图** | 实际调色的输入源 | 完整解析编码、相机色彩矩阵、白平衡与初始几何 |
| **基础显影预览** | 快速浏览源图内容 | 仅用于人类或前置浏览，不参与传感器线性基线计算 |
| **后端基线（v0）** | 后端建立的初始干净渲染 | 实际编辑与版本树的起点 |
| **父/子候选图（Parent / Child）** | 评估单步操作效果 | 绑定同一次编辑前后的两个相邻版本 |
| **实际导出 JPEG** | 最终交付物与 G4 验收图 | 由后端全尺寸渲染导出，重新解码后送入 G4 检查 |

仓库内置的 `paired photos/DSC_3734/` 展示了前三种角色的原始文件示例：`.NEF`（RAW 源）、普通 `.JPG`（512×768 Display P3 作者目标）以及 `o` 前缀 `.JPG`（512×768 sRGB 基础预览）。

## 2. 色彩管理与观察图规范

由于 Display P3 与 sRGB 下相同的 RGB 数值对应完全不同的颜色，系统在图像流转中执行统一的色彩规范：
- **模型输入标准**：所有送入视觉模型的观察图均派生为 **upright（方向已校正）、RGB8、sRGB PNG**，并剥离 EXIF 与文本元数据，防止客户端二次旋转或元信息干扰。
- **真实 ICC 转换**：作者目标图从其源色彩空间（如 Display P3）通过真实 ICC 配置文件转换至 sRGB，原始高精度母版保持只读。
- **多源独立路由**：已显影的 JPEG/PNG/TIFF 输入会校验 ICC、位深、方向和 Alpha 通道。16-bit 图像在完成关键色彩转换前保持高位深；灰度、CMYK、透明通道和显式线性数据各自走对应处理分支。

## 3. RAW 几何与画布管线

RAW 解析依据实际选中的 IFD 区分 CFA（Bayer）与 LinearRaw，并严格按以下顺序完成单次几何归一：

```text
选中 RAW IFD → ActiveArea → DefaultCrop → Orientation 归一 → 显示网格
```

后端始终在**完整分辨率**下完成调色渲染，再按原始画布比例下采样生成过程观察图与最终 JPEG，全程保持原始宽高比。

## 4. DNG Opacity 通道合成

对于带有独立 `opacity` 平面的 DNG（常见于全景拼接或畸变裁边后的无效区域），系统将其随 RAW 几何同步裁剪定向，并在**线性 sRGB** 空间下与纯白背景合成：

```text
C_linear = alpha * RGB_linear + (1 - alpha) * white
```

无效区域保留在完整画布中以维持几何对齐，在视觉分析和区域目标计算中会被识别为拼接白边而非实景高光。

## 5. Tone 阶段的统一灰度转换

为了在 Tone 阶段让 Agent 专注明暗关系而不受色相和饱和度干扰，系统会在观察层将对比图转为统一灰度（后端母版与参数仍保持彩色）。

对已完成 ICC 转换的 sRGB 通道 `c ∈ [0, 1]`，按标准 Rec.709 亮度权重在线性空间计算亮度 `Y`，再重新编码为灰度 sRGB：

```text
c_linear = c / 12.92                         (if c <= 0.04045)
           ((c + 0.055) / 1.055) ^ 2.4     (otherwise)

Y = 0.2126 * R_linear + 0.7152 * G_linear + 0.0722 * B_linear

s = 12.92 * Y                              (if Y <= 0.0031308)
    1.055 * Y^(1/2.4) - 0.055              (otherwise)

RGB_gray = round_half_up(255 * clip(s, 0, 1))   # R = G = B
```

两张对比图采用完全一致的确定性公式，不做自动色阶或直方图匹配。**Tone 阶段送灰度图；G1/G2/G3/G4、Color 与 Joint 阶段送彩色图。**

## 6. `target` 对比与 `effect` 对比

Agent 在不同回合面对两类核心对比：
- **`target` 对比（目标图 vs 当前图）**：诊断“离最终效果还差什么”。
- **`effect` 对比（父版本 vs 子版本）**：验证“刚才那一步操作到底改变了什么”。

每次编辑后优先用 `effect` 复核单步结果，确认符合预期后再按需切回 `target` 推进下一步。

## 7. 局部 ROI 观察与 4×4 网格定位

- **尺寸规范**：每轮最多发送两张独立 PNG（总览图最长边 ≤ 512，局部 ROI 图最长边 ≤ 384），保证细节清晰可辨。
- **4×4 网格元数据**：网格坐标以独立元数据形式提供给模型定位，不直接绘制在图像像素上。
- **跨图区域对齐**：做 `target` 局部对比时，模型需分别指定参考图 ROI 与源图 ROI，并结合材质、受光面/阴影面判断两者是否承担相同摄影角色；做 `effect` 对比时，父子图在同一画布上直接复用同一 ROI，同时检查核心区、羽化邻域及区外整体画面。

## 8. 可选 LAB 色彩统计

系统默认以纯视觉方式驱动调色。在开启量化测量模式时，可通过统一 `sRGB → CIELAB D65` 实现直接对原始图像区域计算 LAB 中位数统计：
- **变化量（Delta）** = 当前版本 − 实际基版
- **残差（Residual）** = 目标版本 − 当前版本

当区域明确为物理对应（`same_region`）时输出目标残差；若仅为语义角色对应（`role_only`），则仅作关系参考。

## 9. 对应源码模块

- `src/photo_image_contract.py`、`src/photo_input_contract.py`：ICC、位深、方向与已显影源路由。
- `src/raw_render_contract.py`、`src/photo_source_router.py`：RAW 类型识别与几何管线。
- `src/photo_resize_contract.py`、`src/photo_opacity_contract.py`：显示缩放与透明区合成。
- `src/photo_stage_observation.py`：灰度派生、阶段观察图生成与 4×4 网格元数据。
- `src/dsh_photo_color.py`：本地 CIELAB D65 色彩统计。
